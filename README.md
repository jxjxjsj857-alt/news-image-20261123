A newspaper front page that sums up Monday 23 November 2026 in one image. COP31 collapses in Antalya — the climate talks end with no deal after splitting over fossil fuels, the longest COP on record — alongside tankers struck in the Strait of Hormuz, the Russian cargo ship Sparta II still smouldering off Finland, and three dead and 36 missing in an Indonesian factory fire, plus a ticker of the day's other stories.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) verifies `entry.png` is a whole 1024 × 1024 PNG and writes its exact bytes to the output directory, so both grading runs write identical bytes.

## The image

`entry.png` (1024 × 1024 PNG) was composed for this bounty: the lead illustration of the emptied COP31 plenary hall in Antalya was generated for this day's news, and the masthead, date line, headlines, story panels and ticker were drawn as crisp vector text so the page stays legible at 300 pixels across. Every story was reported on 23 November 2026.
